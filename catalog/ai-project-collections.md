## Awesome LLM Apps

- **Project link:** [Official source](https://github.com/shubhamsaboo/awesome-llm-apps)

- **Type:** Curated collection of AI agents, agent skills, RAG applications, starter projects and advanced multi-agent examples.

- **Scope stated upstream:** More than 100 examples across model providers and application patterns; the README describes end-to-end testing and an Apache-2.0 repository license.

- **Assessment:** Useful as a discovery and learning resource, particularly for studying implementation patterns and runnable examples. It is a collection, not a single application or framework. Each subproject may have its own dependencies, model/API costs, data requirements and license notices; verify those independently before reuse.

## Awesome AI Apps

- **Project link:** [Official source](https://github.com/Arindam200/awesome-ai-apps)

- **Type:** Curated collection of AI application examples, tutorials and implementation recipes.

- **Scope:** The README organizes projects into starter agents, simple agents, voice agents, MCP agents, memory agents, RAG applications, advanced agents and fine-tuning examples. Its project count changes as contributions are added.

- **Use:** Browse individual subdirectories to study framework integrations and working application patterns. This is a learning and discovery repository, not one installable application.

- **License:** MIT for the collection repository. Check each included example's own license, model terms, API requirements and third-party assets before copying or deploying it.

- **Assessment:** Useful as a broad implementation reference. Do not assume every listed project is maintained, production-ready, free to run or covered by the top-level repository license.

## 📝 Note For Reader

A repository-level license may not automatically cover every model, dataset, asset, external API, or dependency included in a collection. Inspect the specific subdirectory and its notices before copying code or deploying an example.
