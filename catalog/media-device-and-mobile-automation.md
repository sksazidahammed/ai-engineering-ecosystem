## Claude Video / Watch

- **Project link:** [Official source](https://github.com/bradautomates/claude-video)

- **Type / Classification:** Video evidence skill for coding agents.

- **Purpose:** Turns video URLs or local files into timestamped frames and transcripts so agents can inspect visual evidence.

- **Workflow / Requirements:** README describes caption-first processing and optional WhisperX or hosted Groq/OpenAI transcription; supports multiple skill hosts.

- **License / Cost / Status:** Optional transcription may send media or audio to external providers; check local/hosted processing choices.

## Agent Device

- **Project link:** [Official source](https://github.com/callstack/agent-device)

- **Type / Classification:** Cross-platform device automation layer.

- **Purpose:** Lets coding agents inspect, control, debug and verify mobile, web, TV and desktop apps through CLI, MCP or a Node.js API.

- **Workflow / Requirements:** README lists iOS, Android, HarmonyOS, TV platforms, web, macOS and Linux, with simulator/emulator and device workflows.

- **License / Cost / Status:** MIT stated in README; device control can affect real accounts and hardware. Use test devices and least privilege.
