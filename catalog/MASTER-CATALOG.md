## Karpathy-inspired skills: provenance note

The submitted repository is [multica-ai/andrej-karpathy-skills](https://github.com/multica-ai/andrej-karpathy-skills). Its README describes four coding-agent principles and includes Claude Code plugin and per-project instruction installation paths, plus a Cursor rule. Notably, its documented Claude Code marketplace installation command references `forrestchang/andrej-karpathy-skills`, and its raw `CLAUDE.md` example also points to that owner. Treat the multica-ai repository as the submitted distribution/maintenance location, but verify the upstream source and current marketplace instructions before installation. The repository states an MIT license.

## Duplicate handling

The submissions “Skills by Anthropic” and “Agent Skills” referred to the same upstream repository, [anthropics/skills](https://github.com/anthropics/skills). They are represented once in this catalogue to avoid double-counting.

## Count and deduplication

The master index currently contains 187 distinct catalogue records. This is a unique-record count, not a count of every link ever submitted: repeated submissions and aliases are merged. The original version history records submissions, not necessarily net-new unique records. The user-supplied recovery list was used to resolve several previously provisional identities and canonical repository links.

## 📝 Note For Reader

The type labels above are provisional unless the row is explicitly verified. A linked repository is not automatically the canonical project simply because its name looks plausible. GitHub search links are discovery aids, not official project links. Before installing anything, inspect the repository owner, README, recent commits/releases, license, dependency chain, required permissions, and installation scripts. See the [verification policy](../standards/verification-policy.md).
