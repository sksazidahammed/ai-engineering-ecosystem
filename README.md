- **Verified** — the canonical upstream project and its basic identity have been checked against its official source.
- **Candidate — review pending** — a name or URL was submitted, but its exact upstream identity, maintenance state, or intended project has not yet been established.
- **Needs clarification** — the supplied name is ambiguous or points only to a broad search result.
- **Archived / inactive** — use only when upstream evidence establishes that status.

A verified identity does not mean every feature, security claim, or compatibility statement has been independently tested. Check the upstream documentation before installing or relying on a tool.

## Directory principles

1. Prefer official repositories and documentation over reposts, mirrors, and search-result pages.
2. Classify by what a project actually is: skill, plugin, MCP server, CLI, application, library, or framework.
3. Merge duplicate submissions while preserving useful alternate names.
4. Separate verified facts from maintainer claims and editorial assessment.
5. Record licensing, installation requirements, platform support, maintenance signals, and security caveats when verified.
6. Never treat a GitHub URL or a compelling README as proof that a project is safe.
7. Keep updates traceable in [CHANGELOG.md](CHANGELOG.md).

## Reader notes

This is an independent research directory, not an endorsement by the upstream authors. Project capabilities, compatibility, pricing, licensing, and maintenance can change. Confirm current details at the official source, inspect permissions and installation scripts, and test tools in a controlled environment before granting access to private repositories, credentials, or production systems.
